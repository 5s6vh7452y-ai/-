あといくら？ PWA 正式版 v1

1. GitHubで新規公開リポジトリを作成
2. このフォルダ内のファイル5点をリポジトリのルートにアップロード
3. Settings > Pages > Deploy from a branch > main / (root) > Save
4. 発行された https://...github.io/.../ をiPhoneのSafariで開く
5. 共有 > ホーム画面に追加

注意：ファイルをChatGPTのプレビューやiPhoneのファイルアプリで直接開くと、保存・動作が制限される場合があります。公開URLから利用してください。
記録は端末のブラウザ内に保存され、他端末と同期しません。Safariのサイトデータ削除等で消える場合があります。設定の「データを書き出す」で定期的にバックアップしてください。画像メモはバックアップJSONに含まれないため別途保管してください。
予算メモは残額計算には影響しません。
